## 🧭 Overview

This project is a **single-page admission registration form** for UCP's Bachelor Programs, covering personal information, contact details, and degree selection. It was built entirely with **HTML, CSS, and JavaScript**, with a focus on clean structure, responsive design, and interactive user feedback.

## ✨ Features

- 📋 **Multi-section layout** — Personal Information, Contact Information, and Degree Selection organized into clean, card-based sections
- 🎯 **Custom-styled form elements** — styled radio buttons, focus glow effects on inputs, and gradient accents
- ⚡ **Dynamic feedback** — displays the selected degree program instantly using JavaScript when chosen from the dropdown
- 📱 **Fully responsive** — adapts smoothly to mobile, tablet, and desktop screens
- ✅ **Client-side validation** — required fields enforced using native HTML5 attributes
- 🎨 **Modern UI** — gradient header, card shadows, and smooth hover/active button animations

## 🚀 Getting Started

No installation or build steps required — this is a static front-end project.

1. **Clone the repository**
   ```bash
   git clone https://github.com/Sawera-Fareed-gif/ucp-registration-form.git
   ```
2. **Open the file**
   Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox).
3. **Fill out and submit the form** to see the interactive elements in action.

## 📚 What I Learned

This project was built while learning core front-end web development concepts, including:

- Structuring semantic HTML forms with elements like `input`, `select`, `fieldset`, and `textarea`
- Applying CSS Flexbox for layout, along with gradients, shadows, and transitions for a polished UI
- Writing basic JavaScript for DOM manipulation and handling events (`onchange`)
- Debugging common front-end issues (class name mismatches, invalid attributes, layout structure)
- Deploying a static website using **GitHub Pages**
